# 📝 Assignment – Node.js + React.js Full-Stack Setup

This repository contains both **backend (Node.js/Express)** and **frontend (React.js)** code for a simple user authentication and profile management system using **MongoDB** and **JWT**.

---

## 📂 Project Structure & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Lavkus24/Assignment.git
```

**cd backend**

```bash
npm install
npm start
```

**cd frontend**

```bash
npm install
npm start
```
